Build 26 핵심
- Astra A1의 Command Registry/Session/typed-input foundation을 Build25 실제 코드에 통합하고, native transaction은 history recorder가 없으면 fail-closed하도록 강화했다. Persistent commit과 transient finalize를 분리하고 U/REDO의 session 재진입 ownership을 정리했다.
- CAD document context + byId/revision index를 추가해 render/select/snap/modify 정책을 분리했다. Plan Overlay는 CAD에서 선택/검사할 수 있어도 수정할 수 없고, locked layer 객체는 선택 가능하지만 수정은 차단한다.
- 기존 Window/Crossing selection과 Snap을 새 Context 정책 위에 연결하고 endpoint/midpoint/center/intersection 정밀 스냅 경계를 정리했다.
- 실제 CAD Layer definition store를 추가해 빈 레이어 생성, 이름 변경, 삭제(사용 중이면 안전 차단), current layer, lock/unlock, 선택 객체 레이어 재지정을 지원한다. 기존 global AND Region-local visibility 계약은 별도 정책으로 유지한다.
- Metric/Imperial을 동일한 UnitService 경계로 처리하되 기본 경험은 한국어+Metric이다. 내부 geometry는 canonical mm를 유지한다.
- `.ppln` schemaVersion 3에 Layer definitions, current layer, unit system, future-ready `sheets: []` shape를 저장한다. multi-sheet는 데이터 구조만 준비했고 Sheet UI는 아직 없다.
- 첫 native CAD reference command로 LINE을 새 Command Session/Context/Precision/Layer/Undo 경로에 연결했다. cancel은 geometry를 남기지 않고 commit은 정확히 하나의 Undo 기록을 만든다.
- Native DWG 지원은 제품 범위에서 제외한다. CAD 교환은 DXF, 문서 출력 방향은 PDF로 유지한다.
- BUILD26 smoke PASS, core unit 5/5 PASS, 100k synthetic performance check 완료. Synthetic 100k에서 commit/Undo/Redo snapshot 비용이 약 0.95s/1.29s/1.29s로 측정되어 전체 JSON snapshot transaction은 여전히 migration용 임시 안전망으로만 유지한다. 실제 Safari/실제 104k 프로젝트 실기는 남아 있다.

Build 24 핵심

- 좌상단에 잘려 보이던 CAD mapping hidden proxy를 제거하고 CAD `참조 도면`의 명시적 mapping card로 옮겼다. 왼쪽 rail은 약 54px로 compact하게 줄였다.

Build 22 핵심
- CAD 원본 geometry는 층별로 복제하지 않는다. Source CAD는 하나만 유지하고 Floor는 Drawing Region을 참조한다.
- CAD Mode에 `작업 범위`를 추가한다. 전체 도면 또는 특정 Drawing Region을 활성화할 수 있고, Region 범위에서는 CAD render/selection/hit-test/snap/TR·EX boundary/layer count가 해당 working set만 사용한다.
- Region working set은 revision/region 단위로 cache하여 매 pointer/render마다 전체 CAD object array를 다시 만드는 일을 줄인다.
- Plan→CAD 전환은 활성 Floor의 연결 Region을 자동 작업 범위로 선택한다. 필요하면 `전체 도면`으로 복귀할 수 있다.
- CAD Mode의 Plan semantic overlay는 기본 OFF이며 사용자가 명시적으로 켤 때만 현재 작업 Region과 연결된 Floor의 Plan 객체를 표시한다.
- Plan Mode는 활성 Floor의 linked CAD Region만 reference로 렌더한다. 다른 층 linked reference는 render 대상에서 제외한다.
- CAD 참조 도면 패널에서는 Floor용 linkedCadRegion을 외부 참조처럼 중복 노출하지 않는다.
- CAD Mode TR에도 클릭 전 빨간 삭제 예정 segment preview와 cut marker를 제공한다.
- 사용자 실제 창의관 Build20 프로젝트 기준 raw CAD 104,498개 중 Region bounds 후보는 6F 7,867개(7.53%), 5F 11,204개(10.72%)로 확인했다. 이는 working-set 축소 가능성의 데이터 확인이며 실제 Safari 체감 FPS/메모리는 사용자 실기 검증이 필요하다.
- Build 21 command/EX/Shift/Space/Door/Fire/FACMAP 계약은 회귀 보존한다.

Build 21 핵심
- Plan Command 상태를 단일 `activeCommand`로 정리해 TR→EX / EX→TR 전환 시 이전 명령이 클릭을 가로채는 문제를 방지한다. Plan Shift는 명령 반전이 아니라 기하 제약에만 사용한다.
- EX는 실제로 교차한 정확한 boundary에만 접합하고 주변 선을 재검색하지 않는다. stale auto-junction dependent를 분리해 무관한 벽이 함께 끌려오는 회귀를 막는다.
- Shift 후보를 GLOBAL 45°와 연결선 기준 REF 45°를 동시에 평가하도록 확장하고, 선 전체 이동에서는 GLOBAL 수평/수직 + 연결선 평행/수직 방향으로 이동축을 제한한다.
- 공간 지정 도구는 Floating HUD와 hover face preview를 제공해 클릭 전에 지정될 공간을 확인할 수 있다.
- 문틀/개구부 전체는 위치 이동 영역, 문짝/개폐호 stroke 근처만 경첩·열림 방향 조작 영역으로 분리한다. 부채꼴 내부는 선택만 한다.
- 요소에 방화문과 방화셔터를 추가한다. FD/FS 표시는 PieniPlan 내부 의미 표식이며 법정 도면 기호를 주장하지 않는다.
- Space는 `도면 계산 면적`과 `관리 면적`을 분리한다. geometry 변화는 관리 면적을 자동 변경하지 않으며 FacilityManager 연동에서도 자동 덮어쓰지 않는다.
- 최근 편집 작업 100건을 compact debug edit log로 프로젝트에 보존해 TR/EX/접합 문제를 재현하기 쉽게 한다.
- 배포 ZIP 권한은 폴더 755 / 일반 파일 644로 정규화한다.
